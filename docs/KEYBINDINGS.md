# Atalhos de teclado

## Navegação

- `↑/↓` — mover seleção
- `Enter` — confirmar
- `Esc` — cancelar / voltar

## Trading

- `o` — abrir formulário de ordem
- `Shift+O` — ordem market rápida (confirmação dupla)
- `x` — cancelar ordem na lista

## Risco

- `l` — editar limite de exposição
- `k` — kill switch (cancelar todas + bloquear novas ordens)
